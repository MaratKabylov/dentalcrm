# Матрица проверки филиального доступа

Матрица относится к миграции `202609260006_enforce_branch_data_access.sql`.
Для проверки используются два активных филиала: `A` и `B`, данные каждого
филиала и одна общая карточка пациента с медицинской историей в обоих филиалах.

| Пользователь | Доступ | Календарь, CRM, задачи | Финансы и касса | Склад и аналитика | Пациент и медицинская история |
| --- | --- | --- | --- | --- | --- |
| Владелец | Все филиалы | A + B | A + B | A + B | Полная история |
| Администратор A | Только A | Только A и общие записи | Только A | Только A | Полная история A + B |
| Управляющий B | Только B | Только B и общие записи | Только B при наличии права | Только B при наличии права | Полная история A + B при `clinical.read` |
| Сотрудник без филиалов | Нет филиалов | Только общие CRM/задачи | Нет филиальных данных | Нет филиальных данных | Карточка пациента и история при профильных правах |
| Пользователь без профильного права | Любой | Нет данных модуля | Нет данных модуля | Нет данных модуля | Только в пределах выданных прав |

## Обязательные сценарии

1. Прямой `SELECT` и read-only RPC возвращают только разрешённые филиалы.
2. Фильтр с идентификатором недоступного филиала возвращает пустой результат.
3. Создание, изменение, архивирование и удаление филиальной записи через
   `security definer` RPC завершается ошибкой `42501`, если филиал недоступен.
4. Дочерние записи проверяют филиал родителя: позиции счёта, смены кассы,
   движения склада, активности лида и история статусов записи.
5. Общие лиды, задачи, кампании и сообщения без филиала доступны по профильному
   праву всей организации.
6. Карточка пациента, медицинские записи, планы лечения и одонтограмма не
   фильтруются по филиалу; клиническая запись изменяется только сотрудником,
   имеющим доступ к филиалу приёма.
7. Агрегат «Все филиалы» складывает только филиалы, доступные пользователю.
8. Фоновый сервис без пользовательского JWT продолжает выполнять системные
   операции; пользовательский JWT никогда не обходит филиальный контроль.
