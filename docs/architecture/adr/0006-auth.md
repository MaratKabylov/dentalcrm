# ADR 0006: OIDC authentication with application authorization

- Status: accepted
- Date: 2026-09-15

## Decision

Delegate authentication and MFA to an OIDC provider. Verify JWTs in the API, then resolve an active tenant membership and permissions in the application database. Do not treat provider roles as business authorization.

## Consequences

The identity provider can be replaced without rewriting RBAC. Revoking a membership immediately removes application access even if an access token is otherwise valid. Development headers are explicitly prohibited in production configuration.
